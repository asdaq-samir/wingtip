# 0022. The app is free for now

- **Date:** 2026-11-02
- **Status:** Accepted

## Context

A paywall before there are users to pay would only slow growth.

## Decision

Wingtip Maps is free while the owner builds the user base. The subscription is parked (issue #217), and IFR planning is free (#216). Research-only data licences are acceptable for internal testing only; research data is never shipped.

## Consequences

Do not build a paywall or gate a feature. See the pricing-and-paywall skill before any paid feature.
