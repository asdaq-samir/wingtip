# 0017. Discrete settings are menus or segmented controls, not sliders

- **Date:** 2026-10-15
- **Status:** Accepted

## Context

A slider for the checkpoints' zoom level, a discrete setting, was rejected.

## Decision

A discrete setting is a Select (dropdown) or a segmented control, never a slider.

## Consequences

A slider is for a continuous value only.

## Source

The owner asked for the dropdown back; CLAUDE.md, The app on the phone.
