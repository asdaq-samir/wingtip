# 0014. One home per control

- **Date:** 2026-10-27
- **Status:** Accepted

## Context

The same setting in two places left pilots unsure which one counted.

## Decision

Every control lives in one place only. Setup's tiles are FPL, Theme, Layout and Appearance (Alerts moved to the Map menu on 2026-11-05); everything else is in the Map menu; there is no Settings page.

## Consequences

Adding a control means choosing its one home and removing it from anywhere else.

## Source

The owner, 2026-10-27 and 2026-11-05.
