# 0014. One home per control

- **Date:** 2026-10-27
- **Status:** Accepted

## Context

The same setting in two places left pilots unsure which one counted.

## Decision

Every control lives in one place only. Setup's tiles are FPL, Theme, Layout and Appearance (Alerts moved to the Map menu on 2026-11-05); everything else is in the Map menu; there is no Settings page.

## Consequences

Adding a control means choosing its one home and removing it from anywhere else.

## Source

The owner, 2026-10-27 and 2026-11-05.

## Amended 2026-11-10

The one search replaced the sheet's four tabs (FPL, Airport, Airplane,
Setup) on all three apps on 2026-11-09, and on 2026-11-10 the owner had
the account button open Settings at once ("When tapping the avatar just
open the settings"), with no menu between. So there is a Settings page
now: the account button's, holding what Setup's tiles and the account
menu held. The map's switches, the alerts and Airport Weather are the
Map card's, opened by the map's own Map button as Apple Maps opens its
Choose Map card (Settings' Map row opens the same card). The rule itself
stands: each control has one home. docs/navigation.md lists them.
